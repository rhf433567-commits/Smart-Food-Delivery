
# 🚚 Smart Food Delivery

## فكرة المشروع
يهدف المشروع إلى تحليل أوقات توصيل طلبات الطعام ومعرفة العوامل المرتبطة بتأخير الطلبات، وتوفير أداة تساعد العميل على تقدير وقت التوصيل المتوقع.

## المشكلة
قد يحصل العميل على وقت توصيل غير دقيق، مما يؤدي إلى تأخر الطلب وانخفاض رضا العميل.

## البيانات المستخدمة
استخدمنا Food Delivery Dataset، وتتكون من:
- 45,593 طلبًا.
- 20 عمودًا.
- المتغير المستهدف: وقت التوصيل.

## أهم الاكتشافات

1. **كثافة المرور:** بلغ متوسط التوصيل في الازدحام 31.18 دقيقة، مقابل 21.27 دقيقة في المرور المنخفض.
2. **الطقس:** بلغ متوسط التوصيل في الطقس الغائم والضباب 28.92 دقيقة، مقابل 21.86 دقيقة في الطقس المشمس.
3. **فترة الطلب:** بلغ متوسط التوصيل في المساء 29.21 دقيقة، مقابل 21.28 دقيقة في الصباح.
4. **المسافة:** ارتفع متوسط وقت التوصيل في فئة المسافات الأطول مقارنة بفئة المسافات الأقصر.

## مكونات المشروع

- تحليل البيانات وتنظيفها.
- استخراج خصائص جديدة.
- تحليل العوامل المرتبطة بوقت التوصيل.
- Dashboard تفاعلية باستخدام Streamlit.
- أداة لتقدير وقت التوصيل اعتمادًا على الطلبات السابقة المشابهة.

## التقنيات المستخدمة
- Python
- Pandas
- Streamlit
- Matplotlib
- Seaborn
