# 🍔 Smart Food Delivery – تحليل بيانات وتوقع وقت توصيل الطعام

## 📌 نبذة عن المشروع
يهدف مشروع Smart Food Delivery إلى تحليل بيانات توصيل طلبات الطعام وفهم العوامل التي تؤثر على مدة التوصيل، مثل الطقس وحركة المرور والمسافة بين المطعم والعميل.

## 🎯 هدف المشروع
تحليل بيانات التوصيل ودراسة العوامل المرتبطة بمدة وصول الطلب، تمهيدًا لبناء نموذج تعلم آلي يتنبأ بوقت التوصيل.

- نوع المشكلة: Supervised Learning
- نوع المهمة: Regression
- العمود المستهدف: `Time_taken(min)`

## 📊 وصف البيانات
تتكون مجموعة البيانات من:
- 45,593 سجلًا.
- 20 عمودًا.
- بيانات عن موظفي التوصيل والمطاعم والعملاء والطقس والمرور ووقت التوصيل.

## 🛠️ الأدوات المستخدمة
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Scikit-learn (ضمن مراحل بناء النموذج القادمة)

## 🔍 مراحل المشروع

### 1. استكشاف البيانات
- قراءة البيانات وفهم بنيتها.
- فحص أنواع الأعمدة.
- التحقق من القيم المفقودة والتكرارات.
- اكتشاف القيم غير الصحيحة.

### 2. تنظيف البيانات
- معالجة القيم المفقودة.
- تنظيف النصوص والمسافات.
- معالجة القيم غير الصحيحة.
- تحويل أنواع البيانات.
- التحقق من القيم غير المنطقية.

### 3. التحليل الاستكشافي
- حساب المتوسط والوسيط والمنوال.
- دراسة توزيع وقت التوصيل.
- تحليل تأثير الطقس وحركة المرور.
- استخدام الرسوم البيانية لفهم البيانات.

### 4. المراحل القادمة
- استكمال تنظيف البيانات.
- هندسة الخصائص (Feature Engineering).
- حساب المسافات بين المطعم والعميل.
- تجهيز البيانات للتعلم الآلي.
- تدريب نماذج التنبؤ.
- مقارنة النماذج وتقييم أدائها.
- اختيار النموذج الأفضل.

## 💡 أهمية المشروع
يساعد المشروع على فهم العوامل المرتبطة بتأخر طلبات الطعام، والاستفادة من البيانات في تحسين كفاءة التوصيل وتوقع وقت وصول الطلبات.
